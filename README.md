## 🌟 핵심 기능

### 1. 프레임리스 통합 타이틀바 & 완전 자동 숨김 (Edge-to-Edge)
- OS 타이틀 바를 완전 통합하여 캔버스 면적 100%를 오직 이미지 감상에 할애합니다.
- **자동 숨김(H)**: 마우스가 캔버스 중앙에 있으면 상/하단 바가 즉각 사라지며, 화면 끝으로 마우스를 가져가면 딜레이/애니메이션 없이 즉시 나타납니다.
- **네이티브 윈도우 조작**: 8방향 가장자리 리사이징, 창 드래그 및 Aero Snap, 작업 표시줄을 가리지 않는 스마트 최대화(F11 / 더블클릭) 완벽 지원.

### 2. 압축 파일 (ZIP, CBZ) 다이렉트 스트리밍 & 대용량 스마트 메모리 캐시
- 압축을 미리 풀 필요 없이 `System.IO.Compression`으로 압축 파일 내부의 이미지를 0.01초 만에 인덱싱하여 다이렉트 렌더링.
- **계층형 스마트 자연 정렬 (Smart Natural Sorting)**:
  - `001화`, `010화`처럼 앞에 0을 채우지 않은 `1화`, `2화`, ..., `9화`, `10화`, ..., `99화`, `100화`, ..., `1000화` 형태의 폴더 및 파일명도 **`1~9화` → `10~99화` → `100~999화` → `1000~9999화`** 순서로 완벽하게 인식하여 정렬합니다.
  - 압축 파일 내부의 하위 디렉터리 경로(예: `1화/01.jpg` vs `10화/01.jpg`)까지 폴더 계층별로 정밀하게 자연 정렬되므로 에피소드가 뒤섞이지 않고 1화부터 완결까지 순서대로 정주행할 수 있습니다.
- **MB 단위 정밀 메모리 추적 & 듀얼 캐시 정책**: 디코딩된 비트맵의 실제 메모리(RGBA 32bpp)를 실시간 추적하여 지정한 메모리 용량(MB) 또는 페이지 수(장) 내에서 현재 페이지 주변을 최적 캐싱. 초과 시 현재 페이지와의 거리가 가장 먼 페이지부터 자동 해제(Smart LRU Eviction).
- **시스템 물리 RAM 감지 & 1GB 초과 대용량 지원**:
  - 프로그램 기동 시 시스템에 장착된 물리 RAM을 1회만 단독 감지하여 표준 규격(1GB=1024MB, 16GB 장착 시 16,384MB)으로 산출하며, 시스템 메모리의 **절반(16GB 기준 정확히 8,192 MB)까지 슬라이더로 손쉽게 조절** 가능. (최초 실행 시 디폴트값은 256MB, 이후 저장된 값 유지)
  - 슬라이더 우측의 **수동 입력칸(NumericUpDown)** 을 통해 1GB 이상은 물론 **최대 64GB(65,536 MB)** 까지 원하는 용량을 자유롭게 직접 입력 지원.
  - 256MB, 512MB, 1GB, 2GB, 4GB, RAM 50% 빠른 프리셋 버튼 원클릭 적용.

### 3. 인접 압축 파일 (ZIP) 선행 프리캐싱 (Seamless Multi-Volume Reading)
- **권별 시리즈 만화책 무딜레이 연속 열람**:
  - 현재 열려 있는 압축 파일의 같은 폴더 내에 이전/다음 권 압축 파일(예: `1권.zip`, `2권.zip`, `3권.zip`)이 있을 때, 백그라운드 스레드에서 인접 압축 파일을 미리 인덱싱하고 첫/끝 페이지를 사전 디코딩해 둡니다.
  - 1권의 마지막 페이지를 넘길 때 딜레이 없이 **즉각 0.00초 만에 2권 첫 페이지로 전환**됩니다.
  - 반대로 2권의 첫 페이지에서 뒤로 갈 때는 **1권의 맨 마지막 페이지로 자연스럽게 이동**합니다.
  - **설정(`F2`) 옵션 (기본값: 꺼짐)**:
    - `0. 사용 안 함 (꺼짐 - 기본값)`
    - `1. 뒷 파일 1개만 미리 캐싱 (다음 권 ▷)`
    - `2. 앞 파일 1개만 미리 캐싱 (◁ 이전 권)`
    - `3. 앞/뒤 1개씩 모두 미리 캐싱 (이전 권 + 다음 권)`
  - 백그라운드 스레드에서 최소한의 진입 페이지만 가볍게 사전 디코딩하므로 UI 멈춤이나 메모리 낭비가 전혀 없습니다.

### 4. 정밀 애니메이션 GIF 프레임 제어
- 재생 / 일시정지 (스페이스바)
- 프레임 슬라이더 탐색, 1프레임 이전/다음 미세 이동
- 재생 속도 조절 (0.25x ~ 2.0x) 및 현재 프레임 번호/총 프레임 표시

### 5. 전문 이미지 필터 7종 (단축키 0 ~ 6)
GDI+ `LockBits` 및 256-byte LUT 기반의 초고속(1~2ms) 실시간 필터 엔진 탑재:
- **끄기 (`0` / Off)**: 원본 픽셀 보존
- **선명하게 (`1` / Sharpen)**: 3×3 라플라시안 컨볼루션 필터로 경계선 강화
- **흐리게 (`2` / Blur)**: 부드러운 가우시안/박스 블러
- **중간 부드럽게 (`3` / Medium)**: 노이즈 완화 및 스무딩
- **꿀뷰 언샤프 마스크 (`4` / Unsharp Mask - 강력 추천)**: 꿀뷰(Honeyview) 스타일의 가우시안 감산 지능형 선명화. 폰트/선화 외곽선만 또렷하게 살리고 지저분한 노이즈 증폭 억제.
- **스캔본 만화 톤 보정 (`5` / Manga Clean - 스캔 만화 최적)**: 칙칙하거나 누런 종이 배경을 순백(255)으로 깨끗하게 날리고, 흐릿한 펜선과 글자를 진한 딥블랙으로 복원하는 고속 레벨(Levels) 보정.
- **야간 반전 읽기 (`6` / Invert Dark - 눈부심 방지)**: 야간에 불 끄고 만화나 텍스트를 읽을 때 흰색 배경의 눈부심을 차단하는 다크모드 흑백 반전.

### 5.5 이미지 보간 방식 3종 (단축키 I)
- **고품질 쌍입방 (Bicubic - 기본값)**: 만화/일러스트/사진의 부드러운 그라데이션과 자연스러운 곡선 표현 최적화.
- **쌍선형 (Bilinear)**: 가볍고 부드러운 고속 리샘플링 보간.
- **최근접 이웃 (Nearest Neighbor)**: 픽셀 아트, 도트 그래픽, 레트로 게임 캡처에서 뭉개짐(블러) 없이 100% 원본 픽셀 보존.

### 6. 만화책 & 서적 전문 보기 모드 (Comic Viewer Engine)
- **보기 모드 4종**:
  - **1장 보기 (단면 - `Ctrl+1`)**: 일반 단일 이미지 열람.
  - **2장 보기 (우에서 좌 ◁ - `Ctrl+2`)**: 일본 만화/망가 표준. 우측에 첫 페이지, 좌측에 다음 페이지를 배치하여 자연스러운 만화책 읽기 지원.
  - **2장 보기 (좌에서 우 ▷ - `Ctrl+3`)**: 서양 코믹스/일반 서적/잡지 표준. 좌측에 첫 페이지, 우측에 다음 페이지 배치.
  - **웹툰 모드 (세로 무한 연속 스크롤 - `Ctrl+4` / 신규!)**:
    - **가로폭 맞춤(Fit to Width) 고정**: 1장 단면 상태에서 이미지 가로폭이 창 너비에 100% 꽉 차도록 고정됩니다.
    - **컷 간격 0px 무한 세로 스트림**: 낱장으로 잘린 웹툰 컷 이미지들이 아래로 경계선(여백) 없이 완전히 이어져 끊김 없는 정주행 경험을 제공합니다.
    - **부드러운 마우스 휠 스크롤 (Smooth Ease-Out Deceleration)**: 휠을 굴릴 때 툭툭 끊기는 단계적 이동 대신, 60 FPS 고주파 타이머 기반 지수 감속 보간(Ease-Out Lerp)을 적용하여 스마트폰/최신 웹툰 앱처럼 버터처럼 부드럽고 매끄러운 스크롤을 선사합니다. (연속 휠 입력 가속 누적 및 최대 리드 제한 지원, 환경설정에서 On/Off 가능)
    - **스마트 백그라운드 프리캐싱 (Stutter-Free Pipeline)**: 현재 화면에 보이는 컷을 중심으로 앞뒤 10여 컷을 백그라운드 스레드에서 사전 디코딩하여, 초고속 스크롤 시에도 딜레이나 흰 화면 깜빡임 없이 부드러운 60+ FPS 스크롤을 유지합니다.
    - **직관적인 조작**: 마우스 휠 스크롤, 마우스 좌클릭 드래그 패닝, `Space` / `PageDown` (한 화면 넘김), `Home` / `End` (맨 위/아래 이동), `Ctrl+휠` / `Ctrl+0` (줌 및 100% 복원).
    - **스마트 연속 권 전환**: 1화 웹툰의 맨 아래 끝에서 연속으로 휠을 굴리면 딜레이 없이 즉각 다음 화(`2화.zip`)로 자동 전환되어 매끄러운 정주행을 지원합니다.
  - **펼침면 스마트 단독 감지 토글 (`Shift+V`)**: 2장 모드 열람 중 양면 표지나 와이드 일러스트(가로 비율 > 1.15배)를 만났을 때 1장으로 단독 중앙 표시할지 여부를 토글합니다. (**기본값: 끔** - 사용자가 원할 때 언제든 `Shift+V`, 상단 메뉴, 환경설정에서 켤 수 있습니다.)
  - **중앙 접지선(Gutter shadow) 연출**: 두 페이지 사이에 은은한 음영을 주어 실제 책을 펼쳐보는 듯한 입체감을 선사합니다.

### 7. 화면 맞춤 4종 & 작은 그림 확대 제어
- **화면에 맞춤 (`F` / Fit Window)**: 창 크기에 맞춰 종횡비를 유지하며 전체 이미지를 한눈에 확인.
- **꽉차게 보기 (폭 맞춤, `W` / Fit Width)**: 가로 폭을 창 너비에 100% 꽉 채우고 상단부터 표시. (웹툰/스크롤 만화 최적화)
- **꽉차게 보기 (높이 맞춤, `Shift+F` / Fit Height)**: 세로 높이를 창 높이에 100% 꽉 채움.
- **원본 크기 보기 (`O` / Original 100%)**: 축소/확대 없는 1:1 픽셀 원본 렌더링.
- **작은 그림 크게 보기 토글 (`S` / Stretch Small Images)**: 원본 해상도가 모니터/창보다 작을 때 100% 이상 확대를 허용할지(ON) 픽셀 원본을 유지할지(OFF) 원클릭 토글.
- **웹툰/긴 만화 스마트 스크롤**: 세로로 긴 이미지는 마우스 휠 시 페이지가 바로 넘어가지 않고 부드러운 상하 스크롤을 먼저 수행한 뒤, 끝에 도달했을 때 다음 페이지로 전환됩니다.

### 8. 미니맵 내비게이션 (Minimap & Viewport Radar)
- **대형 이미지 및 고배율 확대 시 위치 안내**:
  - 이미지를 확대하여 화면 밖으로 벗어났을 때, 화면 우측 하단에 전체 이미지 축소 썸네일과 함께 **현재 보고 있는 화면 영역(뷰포트 사각형)** 이 미니맵으로 스마트 표시됩니다.
  - **직관적인 클릭 & 드래그 패닝**: 미니맵 내부를 마우스로 클릭하거나 드래그하면 원하는 위치로 화면이 즉각 부드럽게 이동합니다.
  - **토글 지원 (`M`)**: `M` 키 또는 우클릭 메뉴를 통해 미니맵 표시를 자유롭게 켜고 끌 수 있으며 설정이 보존됩니다.

### 9. 돋보기 기능 (키보드 줌 인/아웃)
- **키보드 단축키로 즉각 확대/축소**:
  - `+` (또는 `=`) 키 / 숫자패드 `+`: 화면 중심 기준 1.2배 확대 (Zoom In)
  - `-` (또는 `_`) 키 / 숫자패드 `-`: 화면 중심 기준 축소 (Zoom Out)
  - 마우스 휠 외에도 키보드로 정밀하고 신속한 확대/축소 가능.

### 10. 다음/이전 파일 점프 (`]` / `[`) & 엄격한 포맷 분리 (Strict Format Isolation)
- **혼합 폴더 완벽 대응**:
  - 한 폴더 안에 `a.jpg`, `a.zip`, `b.jpg`, `b.zip` 등이 뒤섞여 있어도 **열람 중인 포맷을 엄격하게 감지 및 격리**합니다:
    - **압축 파일(ZIP) 열람 중**: `]` / `[` 이동 시 **압축 파일끼리만(`a.zip` ↔ `b.zip`)** 순차 탐색하며, 중간에 있는 `a.jpg`, `b.jpg` 등 낱장 이미지는 일절 건너뜁니다.
    - **낱장 이미지 열람 중**: `]` / `[` 이동 시 **낱장 이미지끼리만(`a.jpg` ↔ `b.jpg`)** 순차 탐색하며, 압축 파일은 일절 건너뜁니다.
  - `]` 키: 다음 파일 / 다음 권 압축파일 즉시 열기
  - `[` 키: 이전 파일 / 이전 권 압축파일 첫 페이지로 즉시 열기

### 11. 하단 페이지 슬라이더 & 검색 점프 바 (Page Navigation & Search Scrubber)
- **폴더 및 압축 파일 내 초고속 이동**:
  - **모드 인디케이터**: 압축 파일 열람 시 `[ZIP]`, 일반 폴더 열람 시 `[폴더]` 뱃지 자동 표시.
  - **직관적인 슬라이더 탐색**: 마우스 드래그 또는 클릭 한 번으로 전체 페이지(1 ~ N)를 원하는 위치로 0.00초 만에 부드럽게 스크러빙 탐색.
  - **스마트 검색 & 페이지 직접 점프 바 (`Ctrl+F`)**:
    - **페이지 번호 입력**: 숫자(예: `25`) 입력 후 Enter를 누르면 해당 페이지로 즉각 점프.
    - **파일명 검색 이동**: 파일명 키워드(예: `cover`, `02`, `ch1`) 입력 후 Enter를 누르면 일치하는 파일로 즉시 이동하며, Enter를 계속 누르면 다음 일치 항목으로 순환 탐색.
    - 검색창에 포커스가 있을 때는 뷰어 단축키가 텍스트 입력을 방해하지 않도록 안전하게 분리.
  - **이전/다음 버튼 (`◀` / `▶`)** 및 현재 페이지 번호/총 페이지 수(`15 / 150`, 2장 모드 시 `15-16 / 150`) 실시간 연동.

### 12. 갤러리 썸네일 탐색기 (Gallery Explorer - `E`)
- **폴더 내 압축파일 / PDF / 이미지 시각적 브라우징**:
  - `E` 키 또는 상단 [탐색기] 버튼으로 독립 갤러리 탐색 창 호출.
  - **다중 썸네일 스트립**: 압축 파일(ZIP/CBZ) 및 PDF 문서 내부의 대표 썸네일을 최대 10장까지 가로 스트립으로 실시간 표시.
  - **마우스 호버 스크러빙**: 작은 썸네일에 마우스를 올리기만 해도 상단 대형 프리뷰가 즉각 전환되어 압축을 풀지 않고도 내부 내용을 한눈에 확인.
  - **다이렉트 페이지 점프**: 원하는 썸네일을 클릭하면 해당 페이지/이미지가 뷰어에 즉시 열림.
  - 파일명 실시간 필터 검색, 4종 정렬(이름순, 역순, 크기순, 수정일순) 지원.

### 13. 스마트 윈도우 창 제어 & 제스처 (Window Control & Gestures)
- **창 크기 & 위치 자동 기억**:
  - 프로그램을 종료할 때 현재 창의 화면 위치(`WindowX`, `WindowY`), 크기(`WindowWidth`, `WindowHeight`), 최대화 여부를 `nyaa-settings.ini`에 자동 보존.
  - 다음 실행 시 마지막으로 보던 모니터와 창 위치/크기로 한 치의 오차 없이 자동 복원.
  - 다중 모니터 분리 시에도 화면 밖으로 벗어나지 않도록 작업 영역(WorkingArea) 자동 검증.
- **빈 화면 마우스 제스처**:
  - **빈 화면 마우스 좌클릭 드래그**: 타이틀바가 숨겨진 상태에서도 빈 여백(캔버스)을 마우스 왼쪽 버튼으로 클릭 후 드래그하면 창 자체를 자유롭게 이동.
  - **빈 화면 더블클릭**: 캔버스 빈 영역을 더블클릭하면 창 최대화(Maximize) ↔ 이전 크기 복원(Restore) 즉각 토글. (이미지 위 더블클릭 시에는 화면 맞춤 작동)

### 14. Windows 파일 확장자 연결 관리 (기본 프로그램 등록)
- **클릭 한 번으로 기본 뷰어 지정**:
  - `F2` 환경설정의 **[파일 & 확장자 연결]** 탭에서 지원 포맷의 체크박스를 선택하고 `[선택한 확장자 연결 적용]` 버튼을 누르면 Windows 탐색기 연결이 즉시 등록됩니다.
  - **카테고리 프리셋**: `[🖼️ 이미지만]`, `[📚 만화(ZIP/CBZ)+PDF만]`, `[✓ 전체 선택]`, `[✗ 전체 해제]` 원클릭 지원.
  - **UAC 권한 불필요**: 관리자 권한 없이 현재 사용자(`HKCU\Software\Classes`) 레지스트리에 안전하게 등록되며 언제든 원클릭으로 해제 가능.
  - **셸 캐시 즉시 갱신**: Win32 `SHChangeNotify` 호출로 재부팅이나 로그오프 없이 Windows 탐색기에 즉시 반영.
  - **명령행 자동 등록 지원**:
    - `nyaa-view.exe /register` (또는 `/assoc`): 모든 지원 포맷 전체 자동 연결
    - `nyaa-view.exe /unregister` (또는 `/unassoc`): 모든 연결 즉시 해제
  - **Windows 10/11 기본 앱 설정 원클릭 열기**: 시스템 기본 사진 뷰어 지정 화면(`ms-settings:defaultapps`) 바로가기 제공.

### 15. 파일 삭제 & 휴지통 이동 (Delete)
- **열람 중인 파일 안전 삭제**:
  - **단일 이미지 열람 시**: 현재 보고 있는 이미지 파일 1개를 확인 후 Windows 휴지통으로 이동하고, 자동으로 다음 이미지로 전환.
  - **압축 파일(ZIP/CBZ) 열람 시**: 현재 열람 중인 압축 파일 원본 전체를 확인 후 Windows 휴지통으로 이동하고, 폴더 내 다음 압축 파일로 자동 전환.
  - **PDF 문서 열람 시**: 현재 열람 중인 PDF 문서 원본 전체를 확인 후 Windows 휴지통으로 이동하고, 폴더 내 다음 PDF 문서로 자동 전환.
  - **실수 방지 안전 확인창**: 기본 포커스가 [아니오(No)]로 지정되어 엔터를 연타해도 실수로 삭제되지 않으며, 삭제된 파일은 Windows 휴지통에서 언제든 복원 가능.
  - 우클릭 메뉴의 **[휴지통으로 보내기 (Delete)]** 로도 실행 가능.
