# nyaa-view (냐-뷰)

> **Windows용 경량 이미지 및 만화/전자책 뷰어**  
> 외부 서드파티 패키지나 웹 프레임워크 없이, Windows 시스템 환경에 맞춰 가볍게 동작하도록 제작된 무설치 포터블 뷰어입니다.

---

## 주요 사양

- **실행 파일**: `nyaa-view.exe` (단일 실행 파일, 무설치 포터블)
- **외부 의존성**: 없음 (Windows 내장 .NET Framework 4.8, WIC 코덱, WinRT PDF 라이브러리 활용)
- **네트워크 연결**: 100% 오프라인 동작 (외부 통신, 텔레메트리, 자동 업데이트 수집 일절 없음)

---

## 지원 포맷 목록

### 1. 전자책 및 문서 포맷
- **PDF** (`.pdf`): Windows 내장 네이티브 렌더링 라이브러리 연동
  - 단면 및 양면 보기(우->좌 만화책, 좌->우 서적), 필터, 확대/축소, 패닝 지원
  - 하단 탐색 슬라이더 및 페이지 점프, 인접 PDF 연속 탐색 지원

### 2. 만화 압축 아카이브 포맷
- **ZIP** (`.zip`): 압축 해제 없는 다이렉트 메모리 스트리밍 및 인접 권 연속 탐색 지원
- **CBZ** (`.cbz`): 만화책(Comic Book ZIP) 전용 아카이브 포맷 지원

### 3. 이미지 포맷 (낱장 및 압축 내부 공통)
- **표준 이미지**: JPEG/JPG, PNG, GIF (애니메이션 재생 제어 지원), BMP
- **웹 및 고효율 포맷**: WebP, JPEG-XR (`.jxr`, `.wdp`, `.hdp`)
- **스캔 및 인쇄 포맷**: TIFF
- **그래픽 및 텍스처 포맷**: PSD (플랫 합성본), TGA, DDS (DXT1/DXT3/DXT5/RGBA 지원), QOI, ICO, Netpbm (`.ppm`, `.pgm`, `.pnm`)
- *(Windows 시스템 코덱 설치 시 WIC 연동 포맷 추가 지원)*

## 주요 기능

### 1. 프레임리스 통합 타이틀바 및 자동 숨김
- OS 타이틀 바를 통합하여 화면 전체 영역을 이미지 감상에 활용
- **자동 숨김(H)**: 마우스가 중앙에 있으면 상/하단 툴바가 자동으로 숨겨지며, 가장자리로 이동하면 즉시 표시
- 8방향 가장자리 리사이징, 창 드래그, Aero Snap, 최대화 지원

### 2. 압축 파일 스트리밍 및 대용량 스마트 캐시
- 별도의 압축 해제 과정 없이 아카이브 내부 이미지를 직접 인덱싱하여 렌더링
- **계층형 스마트 자연 정렬**: `1화`, `2화`, ..., `10화`, 하위 폴더 계층 구조를 인식하여 올바른 순서로 정렬
- **스마트 메모리 캐시**: 디코딩된 비트맵 용량을 추적하여 지정한 메모리 용량(MB) 내에서 화면 주변을 캐싱하며, 화면에 표시 중인 페이지는 캐시 한도 초과 시에도 안전하게 보호
- 시스템 물리 RAM 감지 및 환경설정(`F2`)을 통한 캐시 용량 조절 지원 (기본 1024MB, 슬라이더 및 수동 입력 지원, 한도 초과 시 안내 메시지 제공)

### 3. 인접 압축 파일 연속 열람
- 같은 폴더 내 이전/다음 권 압축 파일(예: `1권.zip`, `2권.zip`)이 있을 때 백그라운드 선행 탐색을 통해 권별 만화책 연속 전환 지원

### 4. 애니메이션 GIF 프레임 제어
- 재생 / 일시정지 (Space)
- 프레임 슬라이더 탐색, 1프레임 미세 이동, 재생 속도 조절 (0.25x ~ 2.0x)

### 5. 실시간 이미지 필터 및 보간 방식
- **이미지 필터 7종** (단축키 `0` ~ `6`): 끄기, 선명하게, 흐리게, 중간 부드럽게, 언샤프 마스크, 만화 톤 보정, 야간 흑백 반전
- **이미지 보간 방식 3종** (단축키 `I`): 쌍입방(Bicubic - 기본값), 쌍선형(Bilinear), 최근접 이웃(Nearest Neighbor - 픽셀 아트용)

### 6. 만화책 및 웹툰 보기 모드
- **1장 보기 (단면 - `Ctrl+1`)**
- **2장 보기 (우에서 좌 ◁ - `Ctrl+2`)**: 일본 만화/망가 표준
- **2장 보기 (좌에서 우 ▷ - `Ctrl+3`)**: 서양 코믹스/일반 서적 표준
- **웹툰 모드 (세로 무한 연속 스크롤 - `Ctrl+4`)**:
  - 가로폭 맞춤(Fit to Width) 고정 및 컷 간격 0px 무한 세로 스트림
  - 부드러운 감속 마우스 휠 스크롤 (지수 감속 보간 적용, 환경설정에서 On/Off 가능)
  - 폴더 내 중간 이미지 드래그 시 해당 페이지 위치로 즉시 자동 스크롤
  - 상하 연속 휠 조작 시 다음 화 압축 파일 자동 전환 지원
- **펼침면 스마트 단독 감지 토글 (`Shift+V`)**: 양면 표지/와이드 일러스트 단독 중앙 표시 (기본: 꺼짐)

### 7. 화면 맞춤 및 탐색 편의 기능
- 화면 맞춤(`F`), 가로폭 맞춤(`W`), 높이 맞춤(`Shift+F`), 100% 원본 크기 보기(`O`), 작은 그림 확대 토글(`S`)
- **페이지 넘김 전환 효과**: 1장 및 2장 보기 모드에서 3가지 부드러운 전환 효과(암전/페이드, 좌우 슬라이드, 페이지 넘김/쓸어넘기기) 지원 (`F2` 환경설정에서 선택 가능, 즉각적인 응답을 위해 기본값은 `끄기`)
- **미니맵 내비게이션 (`M`)**: 고배율 확대 시 우측 하단 뷰포트 레이더 및 클릭/드래그 패닝 지원
- **키보드 돋보기**: `+` (확대), `-` (축소)
- **하단 페이지 슬라이더 및 검색 바 (`Ctrl+F`)**: 직접 페이지 번호 점프 및 파일명 키워드 검색
- **갤러리 썸네일 탐색기 (`E`)**: 폴더 내 압축파일/PDF/이미지 시각적 브라우징 및 썸네일 스트립

### 8. 편의 및 안전 기능
- **초회 빠른 설정 가이드**: 최초 실행 시 핵심 조작(마우스 휠 동작 방식) 및 권장 캐시 메모리 용량을 바로 선택할 수 있는 안내 다이얼로그 제공 (추후 `F2` 환경설정에서 상세 변경 가능)
- **확장자 연결 관리**: `F2` 환경설정 또는 명령행 인자(`/register`, `/unregister`)로 Windows 기본 뷰어 등록/해제
- **휴지통 안전 삭제 (`Delete`)**: 현재 열람 중인 파일 확인 후 Windows 휴지통으로 이동 (기본 포커스 [아니오]로 오작동 방지)
- **손상 파일 및 픽셀 폭탄 방어**: 
  - 압축 해제 전 스트림 용량(256MB) 및 디코딩 후 픽셀 한도(최대 65,535px, 최대 1억 픽셀) 사전 검증으로 Decompression Bomb 원천 차단
  - ZIP 파일 자체 손상 시 안전한 에러 핸들링 및 자원 해제
  - 아카이브 내부 특정 이미지 손상(CRC 오류 등) 시 앱 종료나 검은 화면 멈춤 없이 전용 경고 플레이스홀더를 표시하고 연속 탐색 보장 (웹툰 모드 시 손상 페이지 명시)
  - 가용 물리 RAM 감지 기반의 정확한 메모리 부족 / 디코딩 에러 분기 안내

## 개인정보 및 보안 (Privacy & Offline Security)

- **100% 오프라인 동작**: 인터넷 통신, 원격 텔레메트리, 자동 업데이트 체크 등 어떠한 네트워크 전송도 수행하지 않습니다.
- **클린 설정 파일**: `nyaa-settings.ini` 및 최근 열람 목록(`RecentItems`)은 `.gitignore`에 등록되어 있어 Git 커밋이나 외부 유출이 차단됩니다.
- **안전한 레지스트리 조작**: 관리자(UAC) 권한을 요구하지 않고 오직 현재 사용자 프로필(`HKCU`)에만 최소한의 파일 연결을 구성합니다.

## 빌드 방법

Windows 기본 내장 컴파일러(`csc.exe`)를 사용하므로 별도의 IDE 설치 없이 명령 프롬프트에서 컴파일할 수 있습니다:

```cmd
cd native
build.bat
```
